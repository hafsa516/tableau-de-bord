# 📊 Tableau de bord des projets - SEGULA Technologies

Application web pour l'analyse et la visualisation des statuts de projets.

## 🚀 Fonctionnalités

- 📁 Téléchargement de fichiers Excel
- 🔍 Détection automatique des colonnes
- 📊 Génération de tableaux croisés
- 📈 Visualisation interactive des données
- 📥 Export des résultats (Excel et PowerPoint)
- 🎨 Légende colorée des statuts
